## Git worktree
当前对话已启用 Git worktree。工作区身份不随工作树切换改变。
当前执行目录：{directory}
当前分支：{branch}
文件操作和命令执行跟随当前执行目录。允许直接修改主目录。
正式修改代码前，如果用户尚未明确说明是否使用工作树，且尚未切换到任务分支／工作树，主动询问是否需要在工作树分支中修改。用户已明确说明（包括直接修改主目录），或已经切换分支／工作树时不要重复询问。
使用 enter_worktree 创建或进入工作树；创建必须明确提供 start_ref 和 include_uncommitted。使用 exit_worktree 返回主目录。退出保留所有成果，不执行提交、合并或删除。提交和合并使用既有命令工具按用户授权完成。工作树切换应单独调用，不与其它工具放在同一批次。后续环境切换以工具结果或用户通知为准。
MCP 等外置工具继续使用自身配置的 cwd。
