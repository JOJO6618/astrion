# Chrome Cookie 授权迁移到 Astrion

本扩展仅在你点击“授权并导出”、并通过 Chrome 网站权限提示后读取所填网站的 Cookie，将其下载为本地 JSON 文件。没有后台脚本、网站注入脚本、服务器、网络请求或遥测；不会读取密码或直接修改 Chrome 的 Cookie。扩展权限可能由 Chrome 保留，可在扩展设置中撤销，或迁移后移除扩展。

## 使用

1. 在保存登录状态的那个 **Chrome 用户资料**中，进入 `chrome://extensions/`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录（里面有 `manifest.json`）。不需要安装任何 EXE。
3. 打开要迁移的网站，从 Chrome 扩展菜单打开 **Astrion Cookie Migration**。
4. 检查“网站范围”，每行一个域名。例如填写 `example.com` 会包括它及子域名；可以手动增加其它域名。登录流程涉及多个网站时，需把相关域名一并填写，不能保证单个域名包含完整会话。
5. 勾选同意，点击“授权并导出”，在 Chrome 中确认这些网站的 Cookie 访问权限。它会下载 `astrion-cookies-*.json`。
6. 在新版 Astrion 浏览器的“导入”页面选择 **导入导出文件 → 选择 Cookie 迁移文件**，选择 JSON，核对数量和失败原因，再决定保留或覆盖已有 Cookie，最后确认导入。
7. 迁移文件含网站登录凭据，请保存在私有目录，导入后删除；无需发送给 AI 或开发者。迁移完成后可移除扩展并关闭开发者模式。

## 边界

- 支持导出普通与分区 Cookie，保留分区站点与跨站祖先标记；不把分区 Cookie 转换为普通 Cookie。需要能提供完整分区信息的较新 Chrome。
- 不导出 localStorage、IndexedDB、设备密钥或密码；某些网站的登录状态还依赖这些数据或服务器设备校验，导入 Cookie 成功不保证仍然登录。
- 只导出当前 Chrome 用户资料的普通会话存储；默认不包含无痕窗口。
- 单次最多 30 个网站、10,000 条 Cookie、4 MiB。范围过大时请分批导出。
- Astrion 选择文件后先预览，确认后才写入当前 Astrion 用户资料；Cookie 值不进入预览、日志或模型上下文。

密码请使用 **Chrome → Google 密码管理工具 → 设置 → 导出密码**，再在 Astrion 选择密码 CSV。无需使用本扩展。
