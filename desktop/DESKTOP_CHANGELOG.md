# 桌面端更新日志（Windows / Tauri 壳）

> 本文件是 **Windows** 桌面端「软件更新」说明的唯一来源：发布脚本
> `desktop/scripts/release_win.ps1` 提取顶部小节，上传为 `release-notes-windows.txt`。
> **macOS** 桌面端（Electron 壳）自 2026-09-29 起独立维护版本号与日志：
> `desktop-electron/DESKTOP_CHANGELOG.md`（上传为 `release-notes-macos.txt`）。
> 0.4.2 是两条线分开维护的起点，此前版本号与日志为两端共用。

## 0.6.5（2026-10-24）

- 紧急修复：启动后工作区信息无法加载、对话历史区域变空白的问题（启动时的标签恢复打断页面初始化）
- 修复页面关闭后迟到的初始化仍可能重新启动标签恢复的问题
- 任务运行期间发送的消息直接作为引导生效，不再排队等到本轮结束
- 输入草稿按账号、工作区与对话分别保存，切换对话或进出设置后再回来内容仍在；未发送成功的内容会恢复成草稿，不再丢失
- 引导附带的图片与附件同样被正确处理，实时显示与历史记录保持一致
- 桌面端标签栏改由后端统一管理：关闭、删除、刷新恢复更可靠，快速切换不再出现错位或残留标签
- 子智能体改为命名实例：可在同一次对话中创建、命名并多次续接，保留上下文继续工作；全部转为后台运行，完成后以消息通知，主对话不再被占用
- 新增子智能体实例数量设置（默认 20），输入栏显示当前数量并可一键调整
- 子智能体新增「仅工作目录可写」权限档位；每个实例使用独立的浏览器配置，互不干扰
- 运行中可请求压缩上下文：当前回复与工具执行结束后自动压缩并接续同一工作段
- 权限被拒绝后继续执行，不再中断整个任务；子智能体完成后默认保留，可继续按名称续接上下文
- 修复停止后等待状态残留，不再显示过期的思考与工具提示；统一状态栏按钮的间距、圆角与投影

## 0.6.2（2026-10-19）

- 目标模式：重构对话级目标的暂停、继续与恢复逻辑，重启后状态显示更准确，审核改为依据真实执行证据判断
- 目标模式：网络中断后的自动重试更稳定，用量数据刷新不再导致重试丢失
- MCP 浏览器改为按对话隔离：不同对话使用各自的默认 Playwright 配置，不再互相占用导致「浏览器已被使用」启动失败
- 修复 Responses 模型（如 GPT-5 系列）的输出速度统计把思考内容算进正文的问题，速度数值更贴近实际输出
- 移除已不再使用的内置技能，减少无用加载

## 0.6.1（2026-10-17）

- 新增工作区 Git 历史浏览：在侧边栏打开项目的提交历史，逐条查看改动文件与代码差异，也可直接把某次提交交给智能体做评审
- 统一「新建对话」入口：所有新建按钮都进入新对话页，对话改为在发送第一条消息时才真正创建，不再产生空对话；新对话按你的个人默认初始化模型、思考模式、推理强度、工作模式与权限模式
- 执行环境与网络权限改为继承「刚离开的同一工作区对话」；跨工作区新建或直接打开时固定为沙箱 + 受限，不再从历史对话推断
- 顶部栏模型选择现在直接显示推理强度；主智能体新增输出速度（tokens/s）统计
- 接入 CrossPet 桌宠联动：本机装有 CrossPet 时，可在设置中让角色同步智能体工作状态与订阅额度
- 修复网页提取服务配置读取失败被静默吞掉的问题
- 前端产物改为内容哈希命名，修复偶发「界面样式错乱 / 模块加载报错」；同步修复快捷窗口在新产物结构下可能白屏的问题
- 移除个人空间里已不需要的「新建对话按钮行为」选项，新建行为现在统一

## 0.6.0（2026-10-12）

- 修复点击下载没有反应的问题：现在与 macOS 版一致，弹出系统「另存为」窗口由你选择保存位置，覆盖聊天里的文件卡片、`download://` 链接、快捷窗口菜单和文件树右键等全部下载入口
- 新增更新过程日志（数据目录 `logs/desktop-update.log`），更新失败或卡住时可回溯每一步状态与错误信息
- 同步 0.5.5 ~ 0.6.0 的共享能力：对话内可直接渲染界面卡片（`show_ui`）、费用统计（主子智能体花费与币种切换）、跨工作区切换与导航优化、消息归属校验、工具状态四态显示、沙箱工作区边界锚定等

## 0.5.4（2026-10-07）

- 子智能体新增固定权限档位（工作区可写 / 沙箱可写 / 完全访问），创建时确定、运行中不变，越界操作被明确拒绝
- 主智能体新增「单次完全访问」申请：需要越界执行时在输入栏弹出审批，人工与自动审核独立裁决，任一拒绝即终止，授权仅对该条命令生效
- 审批面板重构：人工模式下按钮固定在左下角，自动审核时增加右侧进度区；支持收起、随时手动打开查看最近记录
- 修复中文标点旁的加粗渲染（Markdown 双星号不再因紧跟中文标点而失效）
- 修复 Git 状态栏两侧留白、头像渲染与聊天区布局稳定性问题

## 0.5.2（2026-10-06）

- 极简模式下的过程展示更自然：内容完整输出后平滑呈现，不再出现文字先闪出又变化的情况
- 同一次回复中的操作步骤合并展示，列表更清爽
- 个人空间新增「简略消息显示 → 不显示」选项，可隐藏通知、引导和压缩等系统消息，保留正常用户消息与多智能体通信
- 同步近期共享界面与运行时改进

## 0.5.1（2026-10-05）

- 新增 Windows 快捷对话：在设置 → 快捷对话中启用，默认双击 Alt 唤起或隐藏；可改为左 Ctrl、右 Ctrl 或 Shift
- 支持框选截图、窗口截图、图片粘贴和拖入；截图完成自动恢复输入栏光标，按 Esc 可关闭快捷窗
- 工作区、模型及权限配置集中在设置页，快捷窗保持简洁；工作区和模型留空时继承默认设置
- 启用快捷对话后，关闭主窗口会保留托盘与后台服务；可从托盘重新打开主窗口或退出应用
- 同步近期共享界面与运行时改进，包括流式文本和思考显示、对话压缩、子智能体能力分档及个人指令拦截

## 0.4.3（2026-10-01）

- 修复开启系统代理时顶部导航栏操作失效的问题：本机桌面控制桥始终直连，恢复窗口最小化 / 最大化 / 关闭、设置入口、对话标签新建 / 切换 / 关闭及窗口拖拽
- 修复同一原因导致运行数据目录设置提示「无法连接更新服务」的问题；正常外网请求仍按原有代理配置访问
- 控制桥返回 HTTP 错误时不再按成功结果处理

## 0.4.2（2026-09-29）

- 新增「运行数据目录」设置（设置 → 通用）：可把应用数据（对话、工作区、日志）放到指定目录，并选择「迁移现有数据」或「直接使用目标目录」；迁移在下次启动时完成，迁移期间显示进度窗口，失败会自动回到原目录并在设置页说明原因
- 迁移会校验复制结果，仅在全部一致时才切换目录；环境变量 `ASTRION_DESKTOP_DATA_ROOT` 存在时以其为准，设置页只读展示
- 修复从开始菜单 / 桌面图标启动时命令环境不完整的问题：桌面后端现在从系统注册表补齐用户 PATH（只在末尾追加缺失项，不改变已有条目顺序），智能体执行的命令能找到你自己安装的 node / python / git 等
- Windows 上一版为 0.3.4，本次一并包含此后累积的界面改进（预览面板、顶部对话标签条、无边框窗口等）

## 0.3.9（2026-09-28）旧内核收官版

- **【重要】看到本提示请勿点击「更新」按钮**：本版本只是迁移通知——macOS 桌面版自 0.4.0 起更换为 Chromium 内核，旧内核版本无法通过自动更新升级，点了更新也到不了新版，提醒还会消失
- **正确做法**：直接前往下载页 https://astrion.cyjai.com/download.html 手动下载 0.4.0 安装包，覆盖安装即可（对话与设置数据完全保留），之后恢复自动更新
- 0.4.0 更新内容：修复对话区向上滚动经过消息时页面抖动等一系列仅 mac 端出现的问题；新增顶部对话标签条（⌘T 新建 / ⌘W 关闭）；滚动跟随与展开收起的稳定性改进

## 0.3.8（2026-09-27）

- 新增顶部对话标签条：像浏览器一样在窗口顶部并列管理多个对话，点按切换、⌘T 新建、⌘W 关闭，运行中的对话有蓝点提示、完成未查看有绿点提示；标签条独立于主页面，切换页面/刷新/进设置页都不会闪动或消失
- 新增「预览」面板：智能体创建的 HTML 页面、启动的本地服务会自动收录到右侧快捷窗口，点击即可在应用内嵌预览，无需手动打开浏览器
- 修复很短的对话（如一问一答）有时不显示自己发送的消息气泡的问题
- 修复展开堆叠块/极简摘要块时内容直接往屏幕外长、不再自动跟随滚动的问题
- 修复追底状态下折叠块时整个页面突然向上跳的问题
- 路径授权新增「当前工作区」作用域：可以为单个项目单独追加授权路径，与全局授权叠加生效
- 个性化配置存储优化：搜索/提取服务设置与 API 密钥独立存储，密钥文件改为仅本人可读的严格权限

## 0.3.7（2026-09-27）

- 重构对话区滚动锁定：流式输出期间上翻浏览历史后，向下轻轻滚动不再被瞬间拽回底部，只有真正滚到底才恢复自动跟随
- 修复极简模式下内容时不时上下晃动几个像素的问题
- 流式输出期间拖拽滚动条现在可以正常解除自动跟随（此前基本无效）

## 0.3.6（2026-09-27）

- 修复极简模式摘要块在桌面端（Safari 内核）收起时内容瞬间消失、收起动画丢失的问题，展开/收起全程平滑
- 修复堆叠块模式两类动画问题：单个块收起时内部文字瞬间消失；多个块收起时外壳下边缘与内容不同步、明显慢一拍
- 修复终端命令长时间等待期间「停止」按钮失效（点了看似成功实际停不下来）的问题
- 修复任务被强制取消后对话历史损坏、后续发送报错（API 400）的问题；已损坏的历史对话现在可以自动恢复

## 0.3.5（2026-09-27）

- 修复无法将文件/图片直接拖入窗口的问题：此前拖放被桌面壳层拦截，拖入毫无反应；现已恢复页面原生拖放，文件/图片拖入窗口即可附加到输入栏

## 0.3.4（2026-09-26）

- 修复 OpenAI（Codex）OAuth 登录无法打开授权页：浏览器模式与设备码模式的授权链接现在都会调起系统浏览器
- 修复点击对话中的链接会把 Astrion 页面变成目标网站的问题：所有外部链接统一改为在系统浏览器打开
- 修复沙箱安装在最后一步拉取工具链失败（提示 temporary error）的问题：现自动检测沙箱网络并重启 WSL 虚拟机恢复，无需手动操作
- 搜索支持多服务商（博查/Exa/Parallel/SearXNG），网页提取可选 Jina/Tavily/Exa/Parallel（默认 Jina）
- 新增 7 家编程订阅套餐提供商目录，模型列表支持静态回退
- 修复标题生成模型下拉不加载列表的问题；Windows 选择文件夹改用新版系统对话框

## 0.3.3（2026-09-26）

- 修复沙箱安装在部分设备上只报「不存在具有所提供名称的分发」、看不到真实原因的问题：现在直接显示真实错误，识别到虚拟机平台未启用时给出明确操作指引
- 沙箱环境检测新增「虚拟机平台未启用」识别：WSL 已安装但缺少该 Windows 功能时，安装向导会引导管理员授权启用并提示重启（此前会直接安装失败）
- 修复损坏的系统缓存文件导致沙箱安装反复失败的问题：现在自动检测并重新下载

## 0.3.2（2026-09-26）

- 修复软件内更新/覆盖安装/卸载时报「Error opening file for writing」：后端进程未随壳退出残留文件锁，现安装前自动清理（若本次更新仍遇该提示，退出应用后点「重试」即可）
- 后端进程更名 astrion-backend.exe：任务管理器中可辨识，安装器可精确清理不再误伤系统 Python
- 壳异常退出时系统级自动收尸后端进程，杜绝残留
