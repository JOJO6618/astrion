# 运行对话加载调查：隔离时序复现

运行：

```bash
node test/2026-10-07_运行对话加载调查/loading_races.cjs
```

此脚本用仓库已有 TypeScript 编译器转译当前源码，在独立 VM 中调用真实 bootstrap、任务恢复、状态对账、历史读取、AI 容器创建与任务轮询方法。网络、计时器、辅助 store 和组件宿主均使用显式模拟；不启动服务、不读取真实对话、不执行模块中的实际依赖。

六组 `CONFIRMED` 验证当前问题可以在指定响应顺序下发生：

1. 迟到 bootstrap 覆盖已加载的新对话。
2. 布局等待期间对账从 0 接管，正式恢复跳过，保留磁盘 assistant 后又创建 assistant。
3. 重新接管同一 taskId 后接受旧响应，且旧 finally 清掉新请求的单飞标记。
4. 旧任务的迟到 404 停止新任务。
5. response.json 之前的身份校验不能拦住解析之后跨对话回写。
6. from=0 冷恢复遗漏事件窗口截断检查。

这些断言是问题确认实验，不是修复后的合格回归。未来重构时应改成断言旧响应被隔离、旧历史不叠加、游标与快照一致、新请求归属不被改变、缺口得到完整快照恢复。

第 2 组验证的是真实方法之间的交接与新建容器，不冒充真实浏览器视觉复现。其他组件、副作用、后端事务与磁盘保存没有在本脚本中测试。

完整源码证据与重构讨论见 `docs/2026-10-07_运行中对话加载调查.md`。
