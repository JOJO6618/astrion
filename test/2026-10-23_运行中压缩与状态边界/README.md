# 完全访问拒绝、形象文字与运行中压缩

## 已确认的行为

- 完全访问申请被拒绝后命令不执行，回填拒绝结果，智能体继续；普通人工工具审批拒绝保持原有语义，用户主动停止仍取消任务。
- 形象文字只显示当前思考或真正执行中的工具 intent。模型生成工具参数、工具间隙留空，不借用上一次内容；“等待 API 响应…”保持原来的显示规则。
- 运行中点击压缩在原任务排队，完整模型响应和整批工具结果回填后压缩，成功后沿原工作段继续。重复请求合并，停止取消待执行请求；无工具回复同样兑现请求。
- 既有任务继续原事件游标，排队状态随显示快照恢复，迟到 ACK 不得回退阶段。

## 人工验收

这些是离线行为回归，不代表真实模型或视觉已验收。应用重启加载后端修改后，请实际观察：

1. 拒绝一次完全访问申请，确认模型收到拒绝并继续处理任务。
2. 思考转入长工具参数生成时，形象文字清空；工具开始执行后显示当前 intent；API 等待提示保持正常。
3. 执行一批工具期间点击压缩，确认先显示等待，整批结束后压缩，再继续原任务；等待时切换对话再回来、或停止任务，状态符合对应行为。
