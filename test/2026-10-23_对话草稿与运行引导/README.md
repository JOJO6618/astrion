## 覆盖范围

- 每对话、工作区、账号和空页的草稿隔离；文字、技能引用、富文本元数据、图片及文件保留。
- 本地编辑在断网、整页销毁及设置页往返后恢复；服务器恢复连接后同步。
- 旧保存 ACK、旧读取、导航后引导响应不清除新输入或目标对话内容；新空页创建真实对话后转移草稿归属。
- CAS 拒绝多窗口旧写，丢失保存响应后对账；空草稿保留水位，原子写失败保留旧文件。
- 引导接受成功只清提交版本；附件-only 可以发送，拒绝/失败保留原输入。
- 图片与文件通过独立隐藏路径通知交给模型，路径-only 引导不会调用图片多模态构造。
- 同一任务安全边界消费引导、原子关闭受理，停止及错误对话拒绝；压缩续接重新开放同一任务的引导受理。
- 未消费引导和旧提前输入只恢复草稿，不自动发送；图片/文件经过公开快照仍保留，草稿保存成功才确认移除来源。
- 已显示草稿的 sync 快照立即合并恢复项；初始身份加载期间用户新输入与恢复内容同时保留。

## 人工验收

正常加载新后端代码并更新前端构建后检查：

1. 在两个对话和 `/new` 分别输入不同文字与附件，切换后各自恢复；进入设置再返回、刷新后再次核对。
2. 断网编辑后刷新，确认本地内容仍在；恢复网络后再次打开对话，确认同步。多窗口冲突应提示并保留本地内容。
3. 主任务运行中发送文字、图片或文件，模型收到引导和附件路径；输入栏上方不再堆积提前输入消息。
4. 发送引导请求期间继续输入，确认新编辑保留；任务即将结束或停止时提交被拒绝，原文字和附件保留。
5. 停止一个尚未消费引导的任务，刷新或切回该对话，确认未消费内容恢复到草稿，且不会自己启动新一轮。
6. 在长对话和压缩续接期间重复检查发送与滚动布局。

离线回归与生产构建通过不等于真实长对话卡顿、浏览器视觉或真实模型行为已经验收。没有运行浏览器自动化，没有启动第二个后端。
