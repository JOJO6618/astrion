# 极简摘要动画与并行滚筒回归

2026-10-06 最终约定以用户确认的思考分波 demo 和之后的边界纠正为准。新回归与详细说明见 `../2026-10-06_极简扫光_03/README.md`。

## 显示规则

1. 思考首批以柔边斜光出现。后续整行扫光保留已显示文字并续显新增内容，上一束完全离开后等待 650ms，无新增也继续扫。移动速度 320px/s，不按固定耗时重播。
2. 工具 intent 接收完整才开始入场。`intent_full` 不代表完成，使用后端 `intent_complete` 和 tool_start 完整参数兜底；头像旁提示和共享 intent_rendered 保持独立。
3. 工具已经完整入场后转思考，工具正常退场、保留 90ms 切换间隔、思考正常入场，期间同一思考段的新内容缓冲。
4. 尚未显现的内容被模型后续思考、正文或下一批工具超过时，跳过旧动画立即完成显示；正文开始时的空 text action 已算推进。
5. 同一批并行工具是明确例外：后续成员开始调用，继续播完首项入场再进入滚筒，不瞬间结束。滚筒保留 1450ms 轮换、520ms 滚动、170ms 回弹、26px 行高和 2px 过冲。
6. 并行批次部分完成保留所有成员，全批完成静态停最后一项；新批次取消旧计时器和过期收尾。

## 验收

前端代码已构建。由于本次增加后端 intent 完成信号，重启当前后端并刷新页面后由用户实际验收。用户明确本项后续迭代不要每次重复自动跑测试，视觉效果也不由截图自动验收替代。
