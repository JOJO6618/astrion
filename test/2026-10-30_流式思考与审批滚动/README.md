## 覆盖范围

- 真实 `elementScrollFollow.ts` 与 `useScrollControl.ts` 经 TypeScript 转译后运行，使用 Vue `nextTick` 验证 DOM 提交后追底。
- 连续 100 次流式增长不误脱锁；Markdown 子节点异步增高且没有后续模型 chunk 时仍能追底。
- 手动滚轮、触摸、键盘、滚动条拖动脱锁；下滚近底回锁；布局缩小保持锁定。
- 旧节点替换、对话引用变化、DOM 断开和卸载后不继续写入，正确移除监听及尺寸观察。
- 从当前 `ChatArea.vue` 抽取实际的滚动监听、内容尺寸观察、追底函数，验证审批底部占位被观察，视口/占位收缩不触发大幅位移误脱锁，已脱锁阅读不被拉底。
- 从当前 `MinimalBlocks.vue` 抽取实际 ref 注册函数，验证重复 ref 回调不叠加监听、节点替换和卸载清理、历史已完成分组展开不自动追底。
- 嵌套思考区输入不解除外层对话锁定。

合计 21 项离线回归。DOM 尺寸、滚动条事件和 ResizeObserver 使用受控模型，不等同于真实 Chromium 的排版、事件顺序或动画视觉验收。

## 用户复测

1. 展开正在生成的极简行，让思考内容持续超出六行，确认内部仍持续追底。
2. 在思考区手动上滚，确认可以停留阅读；下滚到底，确认恢复追底。
3. 打开普通审批或完全访问面板，处理后折叠，再让模型继续输出，确认主对话保持原有锁定。
4. 主对话上滚脱锁后收放面板，确认没有被自动拉回底部。
