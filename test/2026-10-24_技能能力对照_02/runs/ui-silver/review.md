# 论文阅读工作台改版评审

## 输入页面的5个最重要问题

### 1. 分类导航完全失效
侧边栏的「全部论文」「视觉与图形」等分类按钮点击后没有任何反应。这是一个核心导航功能，用户无法按研究领域筛选论文。**改版处理**：实现了完整的分类切换功能，点击分类按钮会筛选对应topic的论文，同时更新计数。

### 2. 筛选按钮缺少状态计数
四个筛选按钮（全部/未读/在读/已读）只显示文字，没有告知用户每个状态有多少篇论文。用户需要点击每个按钮才能知道结果，增加了认知负担。**改版处理**：每个筛选按钮和分类按钮都添加了计数徽章，实时显示匹配论文数量。

### 3. 详情弹窗交互设计缺陷
- 弹窗位置固定在页面中央，小屏幕会溢出
- 点击弹窗外部无法关闭，必须点「关闭」按钮
- 没有焦点管理，键盘用户容易迷失
- 背景页面仍可滚动
**改版处理**：使用模态框+遮罩，点击外部可关闭；添加背景遮罩blur效果；实现完整的焦点陷阱；背景禁止滚动。

### 4. 状态切换逻辑不完整
原代码点击「标为已读」按钮只能把状态从非「已读」切换到「已读」，无法把「已读」切换到「在读」，也不能把「在读」切换到「已读」。用户需要先标为未读，再选择其他状态。**改版处理**：实现三状态循环切换（未读→在读→已读→未读），操作更流畅。

### 5. 视觉粗糙与响应式不足
- 整体灰色调缺乏层次感
- 卡片视觉平淡，hover效果单一
- `min-width: 980px`限制导致窄屏无法使用
- 没有空状态提示
**改版处理**：采用蓝白配色方案，卡片hover上浮效果，完善的空状态提示，响应式布局支持390px窄屏。
