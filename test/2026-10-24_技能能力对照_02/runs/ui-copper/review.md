# Papertrail 论文阅读工作台 - 改版评审

## 输入页面最重要的 5 个问题

### 1. 状态切换逻辑错误 [P0 - 阻塞]
**问题**：点击"标为已读"按钮时，论文状态只能从 `unread` 切换到 `read`，无法切换到 `reading`。

**原代码**：
```javascript
paper.status = paper.status === 'read' ? 'unread' : 'read';
```
这导致 `reading` 状态无法被改变，用户无法将在读论文标记为已读。

**改版处理**：实现完整的三态切换下拉菜单，用户可以自由选择未读/在读/已读任意状态。

### 2. 侧边栏分类无实际功能 [P1 - 主要]
**问题**：左侧"我的研究"分类点击后无任何响应，视觉上显示为静态文字块。

**影响**：用户无法按研究主题筛选论文，只能依赖状态筛选和搜索，功能受限。

**改版处理**：侧边栏主题可点击筛选，与状态筛选组合使用。

### 3. 响应式布局完全缺失 [P1 - 主要]
**问题**：页面 `min-width: 980px`，移动设备上完全无法使用，工具栏和论文列表溢出。

**影响**：研究生在手机/平板上无法使用论文工作台。

**改版处理**：实现 1440px 桌面、900px 平板、600px 手机三档响应式布局。

### 4. 键盘操作与无障碍支持缺失 [P2 - 次要]
**问题**：无键盘导航支持，屏幕阅读器无法理解页面结构，无 ARIA 标注。

**影响**：辅助技术用户无法使用，键盘用户操作效率低。

**改版处理**：
- 按 `/` 聚焦搜索框
- ESC 关闭详情/下拉
- 侧边栏和按钮支持 Tab 聚焦和 Enter 激活
- 添加 ARIA role、aria-label、空状态 aria-live

### 5. 视觉设计粗糙 [P2 - 次要]
**问题**：对比度不足（#747474/#aaa）、阴影零偏移、间距不统一、字体无层次。

**影响**：阅读疲劳，长时间使用不舒适。

**改版处理**：基于 craft-floor 原则重建视觉系统：
- 文本对比度 ≥4.5:1
- 阴影有真实模糊与偏移
- 8px 基准间距网格
- 清晰的信息层级

## 改版主要改进

1. **三态切换**：下拉菜单选择未读/在读/已读
2. **侧边栏功能化**：按主题筛选，可与状态组合
3. **完整响应式**：桌面/平板/手机三档适配
4. **键盘支持**：/ 聚焦、ESC 关闭、Tab 导航
5. **无障碍标注**：ARIA 语义、skip link、空状态通知
6. **视觉重构**：对比度、间距、阴影、色彩状态系统
