## 实际页面验收

1. 在个人空间设置默认工作模式/权限/模型/思考/强度，进入 `/new` 检查显示；`default` 强度不应继承旧的 high。
2. 同工作区打开一个 direct+full 对话再点新建：执行环境与网络应继承，其他项按默认初始化（仍受 plan/受限权限沙箱约束）。
3. 从 A 点击 B 分组的新建：保持 B 的 `/new`，不进入 B 活动对话；执行环境/网络为 sandbox+restricted，不从 A/B 历史继承。
4. 在 `/new` 修改所有设置后发送，刷新该对话检查保存值。分别验证普通与多智能体。
5. 测试桌面新标签和跨工作区 new 标签恢复，以及快速切换/加载期间发送。

自动回归和构建通过不代替用户对实际界面、真实模型执行及不同平台环境的验收。CLI/Gateway、工作流激活创建规则不属于本轮统一范围。
