## 用户实际操作验收

签名测试包版本 `0.5.1-test.2`，未上传发布。

1. 完全退出旧版应用后安装测试版，首次从程序坞启动应在后端就绪后打开主窗口，无需再次点击。
2. 打开快捷窗、关闭快捷窗、拖动框选后，主应用程序坞运行点应保持正常。
3. 唤起快捷对话，各个可见且未被遮挡的应用窗口左上角应显示截图按钮。
4. 点击截图按钮应将对应窗口截图加入附件；真正被前方窗口遮挡的按钮区域应继续被裁切。
5. 关闭主窗口仍隐藏而不退出，快捷对话保持可用；菜单退出才结束应用。
