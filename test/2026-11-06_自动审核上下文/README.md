# 自动审核上下文、裁决与执行版本校验

## 本批范围

- 近期5条用户交互（直接／引导／ask问答合计）、5个完整工具调用＋结果，固定计划批准、当前目标与触发消息；去重、真实时序、非JSON纯文本。
- guidance注入标记不造成漏取；系统／子／压缩通知不伪装用户；兼容当前Chat无message_source的普通输入。
- 工具结果按调用配对，当前待审／同批未执行调用不当历史；重复ID保留全部候选并标歧义；缺工具名不升级成问答授权。
- 问答真实状态与原文保存；旧问答缺实际状态保留原文但明确不能独立证明已回答／授权；计划批准绑定当时正文。
- 已受理未消费引导只读快照；审核期间变化自动重审；批准后及启动前输入变化阻止执行。
- 审核正常允许／拒绝，服务或格式故障独立error，不增加needs_human。超限失败关闭，不静默截断正文。
- 单次完全访问默认仍自动＋人工均通过；开启设置才允许自动单独通过。审核构造保留conversation_id与计费。
