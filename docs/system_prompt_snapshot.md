# 主 Agent 系统提示词快照

2026-11-12。适用主 Agent；独立 Chat、子智能体和辅助模型保持各自现有构造方式。工具定义不属于此次重构范围。

## 唯一权威与冻结边界

- `metadata.frozen_system_prompt` 保存主 Agent 完整初始 system 文本，包括当前协议要求的提供商基础指令、Codex 桥接说明、静态规则和动态初始化资料。
- 首个模型请求前一次性生成并原子保存。普通发送、重新加载、恢复、重试只使用这个字段，不重新扫描规范、技能、记忆或重新加载提供商基础指令。
- 同一对话两次压缩之间，禁止替换、删除或重组已冻结初始 system。模式与状态变化继续通过已有运行期间通知传达；通知的角色和传输方式不变。
- 对话压缩允许整体重建。深压缩只在摘要原子提交时失效快照；取消或提交失败不失效。实际发生自动浅压缩时同样失效，没有可压缩内容时不失效。下一次构建使用当时的新模板与资料。
- 不额外处理运行期间切换模型引起的指令或视觉能力差异。历史检查点回溯只恢复消息及其它状态，不替换目标对话当前的系统快照；新建分叉也不从检查点强行装回源对话的冻结正文。

## 源模板与顺序

- 固定规则集中在 `prompts/main_agent/static.txt`，按原文加载，不做 `str.format`，避免 HTML/CSS 示例中的大括号被误替换。
- 动态初始化模板位于 `prompts/main_agent/dynamic/`；权限、执行环境、工作模式、工作区等已有独立动态模板继续复用。
- 静态模板不包含模型身份、创建时间、对话 ID、工作区绝对路径、用户偏好正文、项目规范、技能目录、记忆正文或功能开关值。
- 新布局：提供商必须前置的基础指令／桥接 → 完整静态规则 → 用户及项目资料 → 模型描述与视觉能力 → 初始模式／功能状态／工具目录 → 最近对话／工作区信息／对话留痕目录。
- 支持视觉的模型分为图片、图片＋视频两种动态说明；纯文本模型得到独立的能力限制说明。图片模型不再被告知可以直接查看视频。
- 时间展示为“当前对话开始时间：YYYY/MM/DD HH:MM:SS（时区：UTC±HH:MM）”，来源是对话 `created_at`，不是提示词重建时刻。旧的无时区创建时间按本机时区解释，缺失或无效值明确未记录。

## 旧对话迁移

- 检查新字段是否存在且有效，不通过 metadata 的字段数量判断版本。
- 通用 `read_conversation`、列表、搜索、显示查询仍然只读。主 Agent 首次恢复执行、构建模型上下文前，在存储目录共享锁内检查并转换。
- 有旧冻结内容时按固定的历史顺序合并，不重排、不换成新版模板，也不读取最新资料补写旧冻结段。旧版未独立持久化的固定子智能体协作段按原文字和原位置补入；工作流当前位置不再作为动态初始 system 注入。
- 提供商基础指令与桥接在迁移时一并纳入完整快照。写入新字段并移除旧 `frozen_*_prompt` 字段在同一个存储事务内完成；私有记忆版本与路径等非正文元数据保留。
- 已迁移的旧对话继续沿用旧顺序，直到下一次压缩；压缩后才生成新版静态在前的布局。没有任何旧冻结正文的对话直接按新版初始化。
- 保存失败直接中断构建，不把未落盘快照当成已冻结内容使用。并发初始化在目录共享锁内认领同一快照。

## 执行与协议边界

- 组装和冻结：`core/main_terminal_parts/context/system_prompt.py`；历史消息仍由 `context/messages.py` 构造。
- 元数据键、旧字段次序及压缩失效集合：`modules/system_prompt_snapshot.py`。
- 初始 system 消息带内部 `_frozen_system_prompt` 标记。Responses 不再为该消息重新追加提供商指令，并原样使用完整文本；Chat Completions 的字段清洗不会将内部标记发送给上游。
- 工作流激活／推进／审核／分支／退出继续使用现有工具结果；删除原地刷新工作流 system 段的旁路，不改工具结果和运行期间通知。
- 私有 MEMORY.md 的正文进入完整快照；路径、内容版本、后续写入版本仍独立保存，免预读和冲突检测识别完整快照。子智能体原有私有记忆快照机制不变。
