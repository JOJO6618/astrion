# 对话导出、导入与工作区迁移

2026-10-27。用户确认的两条流程必须保持分离：同一应用、同一机器的工作区迁移直接转移；跨机器通过导出、导入 `.astrion.zip` 文件完成。

## 历史与当前绑定

- 对话 JSON 中的原消息（正文、思考、工具参数及结果、消息 ID、时间、媒体引用）逐值保留，不替换历史路径，不重新执行工具。冻结提示词、压缩记录、Chat 原树及已有分支保持。
- 只更新当前对话身份、工作区绑定、目标模式、迁移资源映射和运行中标记等必要元数据。Chat 清除待执行命令和交接的页面／计时／后台任务资格；保留标签累计数、逐条身份对应及已切换／已继续的历史决定。未完成交接恢复为等待手动选择，副本交接 ID 独立，避免旧操作重放；已有消息不受影响。
- 在最新进度追加一条持久化 user 通知，说明原／目标工作区及环境、资源范围、旧路径含义和当前权限。通知 `starts_work=false`，迁移不创建主任务、不请求模型。Chat 将通知接到 latest_leaf，旧分支不改写；当前分支待处理标签的交接叶节点同步到该通知，通知本身不算用户选择继续。
- 历史不变用于避免不必要的前缀改写，不承诺跨提供商、跨机器仍命中服务端缓存。实际模型／工具环境可能变化。
- 外部导入创建新 ID；内部迁移保留 ID，目标已有该 ID 时明确拒绝。Chat 只能导入 Chat，Agent 只能导入 Agent。
- 目标模型不存在时明确报错；用户可显式改选兼容协议模型，不静默替换。目标执行／网络从 sandbox + restricted 装配，工作／权限取目标默认并经过统一模式校验；冻结的旧环境描述由迁移通知说明其历史含义。

## 必须携带的资源

- 发送过或实际阅读、进入上下文的图片／视频，按 `media_refs` 从媒体库读取规范内容。普通上传附件、源码及其他工作文件不携带。
- 历史引用的压缩摘要与 Chat 交接摘要、对话回顾及交接目录内媒体。Chat 导出按已认证账号的工作区目录解析材料，不创建执行实例。
- 媒体 ID 与内容哈希保持一致。旧格式本地图片／视频没有规范引用时，必须从原可信根内收集并建立路径映射；导入缺资源的包直接失败。
- 恢复到独立 `.astrion/conversation_assets/<新对话ID>/` 命名空间，不覆盖项目已有文件；材料目录结构保持，Markdown 的相对媒体引用继续有效。Chat 材料存账号数据根，不能据此把 Chat 当成工作区。
- 映射保存在 `metadata.conversation_transfer.paths`，媒体重建及 Agent 的 read_file/view_image/view_video 在副本参数上解析，原历史不改写。映射仍走正常权限检查。
- 再次导出必须沿映射带走所有材料，包含未直接出现在正文中的 manifest、回顾及 media 兄弟文件。

## 内部工作区迁移

`POST /api/conversations/<id>/migrate?workspace_id=<源>`，JSON 包含 `target_workspace_id` 与稳定 `operation_id`。

1. 可信身份验证源／目标，在显示锁与主任务门闸内拒绝活动主任务、后台命令或子智能体。
2. 不调用 ZIP 打包／解包。两端媒体库相同时仅核验并复用媒体引用；不读取／复制 blob。媒体库不同时直接复制必要媒体，摘要／材料直接恢复到目标。
3. 完整写入目标及导入回执，随后持久化源侧迁移回执，最后备份并从源索引及文件移除对话。恢复副本存于源数据根 `conversation_transfer_backups/`，原项目与原媒体不删除。
4. 中断后同 operation 重试复用目标，不再追加迁移通知；可继续完成源退役。操作 ID 换目标或换文档被拒绝。
5. 桌面端在导航锁内原位重定位标签，保持稳定 key 和数量；撤销旧导航提交权，再退役源文件。源缓存执行实例解绑并关闭闲置连接，避免旧上下文继续运行。浏览器通过原有工作区导航加载目标。

## 跨机器 ZIP

`POST /api/conversations/<id>/export` 生成下载 URL；`POST /api/conversations/import` 使用 multipart file、operation_id 及可选 model_key。Chat 显式携带 `kind=chat`，Agent 携带 workspace_id。

ZIP 格式 version=1：

- `manifest.json`：format=astrion-conversation，版本、模式、源环境、对话哈希及资源清单。
- `conversation.json`：完整原始对话结构，不使用兼容读取器补字段。
- `assets/<sha256>`：按内容去重的媒体和材料字节。

导入校验文档、全树关系、完整媒体清单、内容哈希及大小；拒绝重复条目、路径穿越、符号链接、加密 ZIP、额外未引用条目。资源总量上限 256 MiB／4096 文件，对话 JSON 上限 32 MiB。导入通过全部校验后才发布完整文件及列表索引。

导出临时包仅在下一次导出时清理同目录中超过 24 小时、严格匹配随机 token 命名的文件，保留符号链接及其他名称。下载必须认证且 no-store；桌面原生另存、Android 桥及网页下载复用共享下载通道。

- 后端：`modules/conversation_transfer/`，`server/conversation_transfer.py`，`server/conversation_transfer_support.py`。ZIP 读取通过只读流适配器支持 Python 3.9 缺少 seekable 的 SpooledTemporaryFile，不额外复制整个上传包；未预期异常的完整堆栈写入 debug_stream.log。
- 前端：共用侧栏、对话菜单导出／迁移及 `ConversationTransferDialog.vue`。按工作区分组时，导入放各工作区的“…”菜单，搜索旁不重复展示；打开文件选择器时捕获菜单目标，后续导航不改写导入范围。非分组模式及 Chat 保留搜索旁入口，Chat 不展示工作区迁移。
