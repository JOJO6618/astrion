# Astrion 桌面端更新日志（Electron 壳）

> 本文件是 Electron 桌面端「软件更新」对话框更新说明的唯一来源。
> 顶部小节对应最新版本；发布脚本从中提取本版本说明上传服务器。

## 0.5.2（2026-10-06）

- 重构极简模式的摘要行显示：工具调用与思考文本改用扫光替换动画，流式更新更顺滑，不再出现半截文字先显示再跳变
- 极简模式下的工具步骤按最近一轮模型响应合并展示，不再跨轮次累积堆叠
- 「简略消息显示」新增「不显示」选项，可隐藏通知、引导与压缩等系统消息，保留正常用户消息与多智能体通信
- 截图按钮改为按出现顺序逐个淡出，快速反复唤起快捷对话时更稳定

## 0.5.1（2026-10-05）

- 修复快捷对话无法正常打开的问题，设置页提前加载已保存配置，避免默认选项闪变
- 输入监控与屏幕录制权限管理移至设置页，返回设置后自动刷新授权状态
- 启动桌面应用时自动打开主窗口，并保留启动期间的程序坞点击意图
- 修复快捷浮窗和截图覆盖层导致程序坞运行点消失的问题，保持跨桌面及全屏可用
- 修复系统截图全屏承载窗口遮挡应用窗口截图按钮的问题
- 修复切回运行中的对话时历史通知重复弹出的问题

## 0.5.0（2026-10-05）

- 新增 macOS「快捷对话」：双击修饰键唤起银白悬浮输入栏，支持五行输入、图片粘贴、流式回复、思考状态与工具进度
- 支持屏幕外拖拽框选截图，以及应用窗口左上角的「发送应用截图」按钮；按钮遵循窗口遮挡关系，截图后保持显示
- 设置新增独立「快捷对话」分区，可指定默认工作区和图片模型，留空跟随全局偏好；快捷对话拥有独立的最近对话列表
- 启用快捷对话后，启动应用即可通过菜单栏使用，主窗口按需打开；当前仍需先启动应用，不包含登录自启动
- 首次使用需按系统提示授权输入监控与屏幕录制
- 传统子智能体新增智能程度分档，可分别配置执行模型与思考能力
- 统一压缩任务的运行、停止与取消行为；停止或失败后保留未消费的提前输入、引导消息及附件
- 修正相关前端格式与代码质量问题

## 0.4.5（2026-10-04）

- 新增个人级「指令拦截」：在 设置 → 通用 中开启后，可自定义拦截规则，包含规则的指令与终端输入会在执行前被拦截，规则对所有工作区生效
- 修复对话区向上滚动时自动追底无法稳定被打断的问题
- 清理前端 lint 错误与未使用声明

## 0.4.4（2026-10-03）

- 修复桌面端自动更新：此前点「安装更新」会报 “Cannot set properties of undefined”，现在可正常下载、安装并自动重启
- 更新检查与下载安装统一到同一份 Electron 清单，版本一致性由发布流程自动保证
- 启动应用时自动检查一次新版本（任意页面进入都生效），有更新即在侧边栏个人入口亮红点

## 0.4.3（2026-10-03）

- 个性化新增「道德偏好」与「成人内容偏好」等级设置，可在个人空间偏好中调整
- 开启系统代理时桌面端的更新检查与窗口控制不再受代理干扰
- 修复展开极简摘要时对话区滚动抖动、回到底部后跟随锁定不稳定的问题
- 流式输出的文字新增浮现效果，思考过程内容支持 Markdown 渲染

## 0.4.2（2026-09-29）

- macOS 桌面端支持在设置中更换运行数据目录，可选择迁移现有数据或直接使用目标目录，并可一键重启应用使设置生效
- 迁移会保留原目录、校验复制结果，并忽略 Finder 自动生成的目录元数据；环境变量 `ASTRION_DESKTOP_DATA_ROOT` 存在时以环境变量为准
- 修复从图形界面启动时桌面后端无法继承用户登录 Shell PATH 的问题
- Android APK 更新入口仅显示在 Android 客户端，不再出现在 macOS 桌面端

> （Tauri 时代历史见 desktop/DESKTOP_CHANGELOG.md）

## 0.4.1（2026-09-29）

- Codex 模型刷新自动读取官方 Codex CLI 最新版本并验证模型目录；网络或新版本异常时自动回退到上一次可用版本
- 预览目标捕捉改为仅采集模型输出链接与 HTML 文件编辑，清理 URL 粘连和无效目标
- 对话区回锁到底部改为短暂平滑补间，用户中途滚动可立即打断
- 对话标签条继续优化首标签颜色跟随侧边栏、长标题淡出，以及 Windows 无边框标题栏的设置和窗口控制

## 0.4.0（2026-09-28）

- 渲染引擎从系统 WebKit 更换为内置 Chromium：修复对话区向上滚动经过用户消息 /
  通知消息时页面上下抖动的问题，一并消除一系列仅 macOS 桌面端出现的动画、
  拖放与兼容性异常
- 新增顶部对话标签条：像浏览器标签页一样新建 / 切换 / 关闭对话，标签上
  实时显示运行状态点；支持 ⌘T 新建标签、⌘W 关闭标签
- 滚动体验优化：回到底部后的自动跟随锁定更可靠（不再出现"要使劲向下滚一下
  才能锁上"的情况）；展开 / 收起内容块时页面视口更稳定
- 预览面板的「外部打开」链接现在会正确调起系统浏览器（此前点击无反应）
- 安装包体积增大：因内置浏览器引擎，安装后约 460MB（此前约 200MB）
