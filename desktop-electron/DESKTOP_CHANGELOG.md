# Astrion 桌面端更新日志（Electron 壳）

> 本文件是 Electron 桌面端「软件更新」对话框更新说明的唯一来源。
> 顶部小节对应最新版本；发布脚本从中提取本版本说明上传服务器。

## 0.4.2（2026-09-29）

- macOS 桌面端支持在设置中更换运行数据目录，可选择迁移现有数据或直接使用目标目录，并可一键重启应用使设置生效
- 迁移会保留原目录、校验复制结果，并忽略 Finder 自动生成的目录元数据；环境变量 `ASTRION_DESKTOP_DATA_ROOT` 存在时以环境变量为准
- 修复从图形界面启动时桌面后端无法继承用户登录 Shell PATH 的问题
- Android APK 更新入口仅显示在 Android 客户端，不再出现在 macOS 桌面端

> （Tauri 时代历史见 desktop/DESKTOP_CHANGELOG.md）

## 0.4.1（2026-09-29）

- Codex 模型刷新自动读取官方 Codex CLI 最新版本并验证模型目录；网络或新版本异常时自动回退到上一次可用版本
- 预览目标捕捉改为仅采集模型输出链接与 HTML 文件编辑，清理 URL 粘连和无效目标
- 对话区回锁到底部改为短暂平滑补间，用户中途滚动可立即打断
- 对话标签条继续优化首标签颜色跟随侧边栏、长标题淡出，以及 Windows 无边框标题栏的设置和窗口控制

## 0.4.0（2026-09-28）

- 渲染引擎从系统 WebKit 更换为内置 Chromium：修复对话区向上滚动经过用户消息 /
  通知消息时页面上下抖动的问题，一并消除一系列仅 macOS 桌面端出现的动画、
  拖放与兼容性异常
- 新增顶部对话标签条：像浏览器标签页一样新建 / 切换 / 关闭对话，标签上
  实时显示运行状态点；支持 ⌘T 新建标签、⌘W 关闭标签
- 滚动体验优化：回到底部后的自动跟随锁定更可靠（不再出现"要使劲向下滚一下
  才能锁上"的情况）；展开 / 收起内容块时页面视口更稳定
- 预览面板的「外部打开」链接现在会正确调起系统浏览器（此前点击无反应）
- 安装包体积增大：因内置浏览器引擎，安装后约 460MB（此前约 200MB）
